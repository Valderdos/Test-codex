# Механика идеального омлета

Одностраничное руководство по приготовлению омлета в стимпанк-стиле. На странице собраны пропорции, пошаговый рецепт, признаки подходящего нагрева, советы и типичные ошибки.

Откройте `index.html` в браузере. Сайт работает без установки зависимостей, сервера или подключения к интернету.

Щёлкните по шкале манометра или потяните стрелку. С клавиатуры выделите манометр клавишей Tab и меняйте положение стрелками.
